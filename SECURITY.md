# Security Policy

## Supported Versions

KnightWarden Core is pre-1.0. Security fixes target the current `master` branch unless a release branch is explicitly documented later.

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting or Security Advisories flow for this repository when available.

If private vulnerability reporting is unavailable, open a GitHub issue with a minimal, non-sensitive summary and ask for private coordination. Do not include exploit code, secrets, credentials, customer data, raw prompts, transcripts, or sensitive logs in a public issue.

## Disclosure Expectations

- We will acknowledge reports as soon as practical.
- We will avoid requesting unnecessary sensitive data.
- We will prefer coordinated disclosure for vulnerabilities with real exploitability.
- We may close reports that rely on fabricated secrets, non-reproducible claims, or unsafe public disclosure of sensitive material.
